# Build with Adesh

Hey! I'm Adesh Kadu, an Artificial Intelligence & Data Science student who enjoys building things for the web and exploring how software works behind the scenes.

This is my personal portfolio — a place where I bring together my projects, skills, education, and internship experience. I built it to introduce myself, share what I've been learning, and make it easier for people to get in touch.

## A little about the portfolio

I wanted the site to feel clean and personal, while still showing some of the things I enjoy working on. It includes:

- A short introduction and links to my professional profiles
- My skills across web development, software development, UI/UX, and AI & Data Science
- A selection of academic and personal projects
- My internship experience and education
- A way to contact me and download my resume
- Dark and light themes, responsive layouts, and subtle animations

## Built with

I used the following technologies to build the portfolio:

- **Next.js** and **React** for the application
- **TypeScript** for the code
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **Lucide React** for icons

## Run it on your machine

If you'd like to explore the project or run your own copy, you'll need Node.js installed.

```bash
git clone https://github.com/B1G0wl/REPOSITORY-NAME.git
cd REPOSITORY-NAME
npm install
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000).

To check the production build, run:

```bash
npm run build
```

Run `npm run start` after a successful build to launch the production version locally.

## Where things live

A few files and folders you'll probably want to know about:

- `app/` — the pages, layout, and global styles
- `data/profile.ts` — the portfolio content, including skills, projects, experience, and education
- `public/` — images, icons, and other static assets
- `public/resume/` — the resume PDF used by the download link

Most of the personal information is kept in `data/profile.ts`, so that's a good place to start if you want to understand how the content is organized.

## Live site

The portfolio can be deployed on [Vercel](https://vercel.com/). Connect the GitHub repository to Vercel, import the project, and deploy it using the default Next.js settings.
